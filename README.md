# Polaria — landing

La landing de Polaria (`/`) y las dos páginas legales (`/privacy`, `/terms`)
que Meta revisa para aprobar WhatsApp Business API.

Las páginas de reserva de cada negocio y el marketplace están en el repositorio
`polaria-explore`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run check   # typecheck + lint
npm run build
```

No hace falta ninguna variable de entorno.

Las convenciones del proyecto —dirección visual, dónde va el copy, qué no
tocar— están en [AGENTS.md](AGENTS.md).
